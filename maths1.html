Row & Column Pictures

What it is

Two ways to read the same system Ax = b. The row picture treats each equation as a hyperplane (a line in 2D, a plane in 3D); the solution is the point where all n hyperplanes meet. The column picture treats the system as one vector equation — a weighted sum of the columns of A equalling b — so solving means finding the right weights.

When to use it
  • Before running elimination, to build intuition for why a system has 0, 1, or infinitely many solutions.
  • To reason about whether a target vector b is even reachable — the column picture is the geometric root of "is b in the column space?" (used constantly in regression: can this outcome be explained by these features at all?).
  • To quickly diagnose a 2×2 or 3×3 system by eye, without setting up full elimination.

How to use it

  1. Row picture: plot/imagine each equation as a line or plane; visually or algebraically find their common intersection.
  2. Column picture: rewrite Ax=b as x₁(col 1) + x₂(col 2) + … = b; ask what combination of the column vectors lands exactly on b.
  3. If the planes are parallel/coincide, or the columns collapse into a lower-dimensional plane that misses b, expect a singular case (see below).
Key fact

Rows are dependent ⟺ columns are dependent, in every dimension. If the row picture breaks down, so does the column picture — this is why the two views always agree on singularity.

Singular cases

  • No solution: planes are parallel / form a triangle in end view (columns lie in a lower-dimensional plane and b sits outside it).
  • Infinite solutions: planes share a whole line/plane (columns dependent, but b happens to lie inside their span).
Cramer's Rule (2×2)
x = (b·d − c·f)/(a·d − b·c),   y = ratio of determinants

Correct but a "total disaster" for large n (uses n! work); Gaussian elimination (~n³/3 ops) is what's actually used in practice and in software.

Gaussian Elimination

What it is

The standard algorithm for solving Ax=b: turn A into an upper-triangular matrix U by forward elimination (subtracting multiples of each row from the rows beneath it), then solve the simple triangular system by back-substitution, from the last unknown up to the first.

When to use it
  • Any time you need to actually solve a linear system numerically — this is the default method every calculator, library, and exam question expects.
  • To test whether a system is solvable, and if so whether uniquely (watch what happens to the pivots).
  • As the engine behind rank, determinant, LU factorization, and inverse — nearly everything else in Unit 1 is built on this one procedure.

How to use it — step by step

  1. Write the augmented matrix [A : b].
  2. Take the top-left entry as the first pivot (assuming it's nonzero).
  3. For every row below, compute the multiplier ℓ = (entry to eliminate) / pivot and do row ← row − ℓ × pivot row to create a zero beneath the pivot.
  4. Move to the next column and repeat with the next pivot, working only on the rows below it.
  5. If a pivot position is zero but a nonzero entry sits below it, swap rows (this is a temporary breakdown — the matrix is still nonsingular). If everything below is also zero, elimination has permanently broken down (matrix singular) — stop and check consistency instead.
  6. Once U is triangular, back-substitute: solve the last equation for the last unknown, then work upward substituting known values into each equation above.
Multiplier & row operation
ℓᵢⱼ = aᵢⱼ / aⱼⱼ    rowᵢ ← rowᵢ − ℓᵢⱼ · rowⱼ

aⱼⱼ is the current pivot; pivots are never zero, because we divide by them.

Breakdown of elimination

SituationMeaningFix
Zero pivot, nonzero entry belowTemporary breakdown — matrix still nonsingularExchange rows, continue
Zero pivot, only zeros belowPermanent breakdown — matrix singularInspect right side: no solution or ∞ solutions
Where pivots appear

Depends only on A, never on b. The right-hand side only decides — in the singular case — between no solution and infinitely many.

Operation count
(n³ − n)/3 ≈ n³/3  (forward)  +  ~n²/2  (back-substitution)

Doubling n multiplies the cost by roughly 8 — this is why factoring once and re-solving (LU) matters for repeated right-hand sides.

Matrix Rank & Consistency

What it is

Rank is the single number that captures the "true size" of a matrix — how many rows (equivalently columns) actually carry independent information. Comparing r(A) to r[A:b] tells you, without fully solving the system, whether it's consistent and how many solutions it has.

When to use it
  • Before solving a rectangular (over- or under-determined) system, to know in advance whether to expect one solution, infinitely many, or none.
  • To detect redundant/dependent rows or columns quickly — e.g. duplicate or derived features in a dataset (multicollinearity), which show up as rank deficiency.
  • As a fast pass/fail test for invertibility of a square matrix (r(A)=n ⟺ invertible).

How to use it

  1. Reduce A (and, for consistency, the augmented matrix [A:b]) to echelon form using elimination.
  2. Count the nonzero rows — that count is the rank. (Do this by elimination, never by hunting through minors — far cheaper.)
  3. Compare r(A) with r[A:b] using the table below to read off the number of solutions.
Useful facts
0 ≤ r(A) ≤ min(m, n)

For square n×n A: r(A)=n ⟺ det A ≠ 0 ⟺ A nonsingular ⟺ A⁻¹ exists ⟺ full set of n pivots.

Consistency theorem — compare r(A) with r[A : b]

ConditionVerdictSolutions
r(A) = r[A:b] = nConsistentExactly one (n − r = 0 free params)
r(A) = r[A:b] = r < nConsistent∞, with n − r free parameters
r(A) ≠ r[A:b]InconsistentNone (a row 0 = c, c≠0, appears)

Elementary row operations never change rank, so it's safe to compute it at any convenient stage of elimination.

LU, LDU & PA = LU Factorization

What it is

Instead of throwing away the multipliers used during elimination, collect them into a lower-triangular matrix L; the resulting triangular matrix is U. Together, A = LU is a complete, reusable record of the elimination that was performed.

When to use it
  • Whenever you must solve Ax=b for the same A but many different b's — factor once, then each new solve is cheap. This is exactly what numpy.linalg.solve and every serious numerical library do internally.
  • To compute a determinant efficiently: det A = ± product of the pivots, in n³/3 operations instead of a catastrophic n! cofactor expansion.
  • Whenever elimination hits a zero pivot in the "natural" row order — use PA=LU (row exchanges) to keep going without declaring the matrix singular by mistake.

How to use it — step by step

  1. Run forward elimination on A as usual, but instead of discarding each multiplier ℓᵢⱼ, store it in the (i,j) position of L.
  2. L gets 1s on its diagonal; U is exactly the triangular matrix elimination produced (pivots on its diagonal).
  3. To use the factorization for a right-hand side b: first solve Lc = b by forward substitution, then Ux = c by back-substitution.
  4. If a zero pivot appears with no way to fix it in place, swap rows and track the swap in a permutation matrix P, giving PA = LU.
  5. For the symmetric LDU form: divide each row of U by its own pivot, collecting the pivots into a diagonal matrix D.
Triangular factorization
A = LU

L = unit lower triangular (multipliers below the diagonal); U = upper triangular from forward elimination (pivots on its diagonal). No extra arithmetic needed — you just record what elimination already did.

Symmetric version
A = LDŪ

D = diag(pivots); L and Ū both have unit diagonals. LU and LDU are uniquely determined by A.

Inverse by Gauss–Jordan

What it is

The Gauss–Jordan method solves n systems at once — Axᵢ = eᵢ for each column eᵢ of the identity — by pushing elimination further than usual: clearing above each pivot as well as below, then dividing every row by its pivot, so [A : I] → [I : A⁻¹].

When to use it
  • When you genuinely need the entries of A⁻¹ themselves — for example a precision matrix in statistics, or a symbolic formula that has A⁻¹ built into it.
  • Not as the everyday way to solve Ax=b — computing A⁻¹ costs three times as much as an LU factorization, and A⁻¹b is no cheaper than two triangular solves. Prefer LU/Gaussian elimination for actually solving systems.
  • To determine invertibility conceptually alongside rank and determinant checks.

How to use it — step by step

  1. Form the augmented block [A : I].
  2. Run forward elimination as usual to reach [U : C] (C turns out to equal L⁻¹).
  3. Continue upward: clear every entry above each pivot, starting from the last pivot and working back to the first.
  4. Divide each row by its own pivot so the left block becomes the identity — the right block is now A⁻¹.
Six facts worth memorising
  • Existence: A⁻¹ exists ⟺ elimination gives n pivots.
  • Solving: x = A⁻¹b is the one and only solution of Ax = b.
  • Failure: a nonzero x with Ax = 0 ⟹ no inverse exists.
  • 2×2 formula: [a b; c d]⁻¹ = (1/(ad−bc))·[d −b; −c a].
  • Diagonal: diag(d₁,…,dₙ)⁻¹ = diag(1/d₁,…,1/dₙ).
  • Reverse order: (AB)⁻¹ = B⁻¹A⁻¹; (A⁻¹)ᵀ = (Aᵀ)⁻¹.
Cost comparison
Computing A⁻¹: n³   vs.   one LU factor + solve: n³/3 + n²

Symmetric A: use A = LDLᵀ, half the arithmetic and no separate pivoting needed.

Vector Spaces & Subspaces

What it is

A vector space is any set of objects (columns, polynomials, matrices, functions…) that is closed under addition and scalar multiplication and satisfies the eight vector-space axioms. A subspace is a subset of a vector space that is itself a vector space under the same operations.

When to use it
  • Whenever you need to check that a set of solutions, functions, or transformed objects still "behaves linearly" — e.g. confirming that all solutions of a homogeneous system, or all symmetric matrices, form a valid space you can take bases and dimensions of.
  • Before applying any later machinery (basis, dimension, rank, orthogonality) — all of it assumes you're inside a genuine vector space or subspace.
  • To quickly rule out a candidate set (e.g. "does this constraint define a subspace, or just a subset?").

How to use it — the subspace test

  1. Check 0 ∈ W — if the zero vector fails the defining condition, stop: it's not a subspace.
  2. Check closure under addition: pick two arbitrary elements of W, add them, verify the sum still satisfies W's condition.
  3. Check closure under scalar multiplication: take an arbitrary element and an arbitrary scalar, verify the result still satisfies W's condition.
  4. If all three hold, W is a subspace; if any fails, it isn't.
Rule of thumb

A set missing the origin can never be a subspace — that's the fastest first check. In short: linear combinations must stay inside.

Every subspace of Rⁿ is one of: {0}, a line, a plane, …, up to an (n−1)-dimensional hyperplane, or Rⁿ itself — and every one of them passes through the origin.

Column Space & Nullspace

What it is

Two subspaces attached to every matrix A. The column space C(A) is every vector reachable as Ax — it lives in Rᵐ. The nullspace N(A) is every x that Ax sends to zero — it lives in Rⁿ.

When to use it
  • C(A): to decide, before solving, whether a given b is even reachable — Ax=b is solvable exactly when b ∈ C(A). This is the geometric root of "can this model fit this outcome at all?" in regression.
  • N(A): to understand non-uniqueness — a nonzero nullspace means the solution (if one exists) is not unique, and describes exactly the redundant/free directions (e.g. a feature that's a copy or sum of others).

How to use it — finding C(A) and N(A)

  1. Reduce A to reduced row-echelon form R.
  2. Column space: identify which columns of R contain pivots; the corresponding columns of the original A (not of R) form a basis for C(A).
  3. Nullspace: the pivot columns give the pivot variables; the remaining columns give the free variables.
  4. For each free variable in turn, set it to 1 and every other free variable to 0, then solve for the pivot variables — this gives one "special solution."
  5. The collection of special solutions (one per free variable) is a basis for N(A).

Column space C(A)

All linear combinations of the columns of A. Subspace of Rᵐ.

Solvability
Ax = b solvable ⟺ b ∈ C(A)

Nullspace N(A)

All x with Ax = 0. Subspace of Rⁿ (only homogeneous systems form a subspace — b ≠ 0 breaks closure).

Special solutions
set one free variable = 1, all others = 0, solve for pivot variables

One special solution per free variable; together they form a basis for N(A).

Four Fundamental Subspaces

What it is

Every m×n matrix of rank r has exactly four associated subspaces — the column space and left nullspace live in Rᵐ; the row space and nullspace live in Rⁿ. Together they explain everything about existence and uniqueness for Ax=b.

When to use it
  • To fully characterise a matrix at a glance: how many independent equations does it really carry (rank), how much redundancy is there (nullspaces), what's the exact reachable output space (column space)?
  • To justify why least-squares residuals are orthogonal to the column space — the left nullspace is exactly where "unfittable error" lives.
  • As the natural setup for the rank–nullity theorem, used constantly when counting degrees of freedom in a model.

How to find each basis

One elimination run (to echelon form U) supplies all four bases at once: nonzero rows of U (row space), pivot columns of the original A (column space), special solutions (nullspace), and the row combinations that produced U's zero rows (left nullspace, found e.g. by solving Aᵀy=0).

Rank–nullity theorem
r + (n − r) = n     r + (m − r) = m
Row rank = column rank

The number of independent rows always equals the number of independent columns — both equal r.

Existence / uniqueness — one-sided inverses

  • Full row rank (r = m): Ax=b solvable for every b (existence). Right-inverse: C = Aᵀ(AAᵀ)⁻¹.
  • Full column rank (r = n): Ax=b has at most one solution (uniqueness). Left-inverse: B = (AᵀA)⁻¹Aᵀ.

Linear Independence, Basis & Dimension

What it is

Independence means no vector in a set can be written using the others (only the trivial combination gives zero). Spanning means a set of vectors can reach every point of a space via combinations. A basis does both at once — independent and spanning — giving every vector in the space exactly one representation. Dimension is the (always constant) number of vectors in any basis.

When to use it
  • To check whether a set of vectors/features carries genuinely new information, or whether one is redundant (a linear combination of the others).
  • To build a minimal, non-redundant representation of a subspace — the foundation of dimensionality reduction (choosing a smaller basis that still spans what matters).
  • To count the true "degrees of freedom" of a space before doing further analysis (e.g. deciding how many parameters a model actually needs).

How to use it

  1. Test independence: place the vectors as columns of a matrix A and solve Ac=0. If the only solution is c=0 (i.e. N(A)={0}, no free variables), they're independent.
  2. Quick rule: any n vectors in Rᵐ with n > m are automatically dependent — there simply isn't room for that many pivots.
  3. Build a basis: if a spanning set is too large, discard dependent vectors (columns without a pivot) until only an independent spanning set remains; if an independent set is too small, add vectors until it spans.
  4. Read off dimension: once you have a basis, its vector count is the dimension — every other basis of the same space will have the same count.
Independence — the test

c₁v₁+…+cₖvₖ=0 only when every cᵢ=0. Test: put vectors in columns of A, solve Ac=0 — independent ⟺ N(A)={0} ⟺ r=n (no free variables).

Spanning

w₁,…,wₗ span V if every v ∈ V is some combination of them. span(W) is always a subspace.

Dimension
dim(V) = number of vectors in any basis for V

A basis is a maximal independent set and, equally, a minimal spanning set — you can't remove a vector without losing spanning, or add one without losing independence.

Linear Transformations

What it is

A transformation T is linear if it respects combinations: T(cx + dy) = c·T(x) + d·T(y). Every linear transformation between finite-dimensional spaces can be written as a matrix once a basis is chosen for the input and output spaces.

When to use it
  • Whenever a rule is claimed to be "linear" (rotation, scaling, projection, differentiation, a neural-network layer) and you need its matrix to actually compute with it.
  • To verify whether a given rule is linear at all — checking T(0)=0 is the fastest way to rule one out.
  • To combine transformations: composing two linear maps is exactly multiplying their matrices, so you can chain rotations/projections/reflections by multiplying.

How to use it — building the matrix

  1. Choose a basis for the input space and a basis for the output space (the same basis, if T maps a space to itself).
  2. Apply T to each input basis vector in turn.
  3. Write each resulting image as coordinates in the output basis — that column of numbers becomes column j of the matrix.
  4. Stack all the columns together: that matrix is the complete representation of T with respect to the chosen bases.

Gram–Schmidt & QR Factorization

What it is

Gram–Schmidt turns any independent set of vectors into an orthonormal one (perpendicular, unit-length) by repeatedly subtracting off the components already captured by earlier vectors, then normalising. Recording the process gives A = QR: Q has orthonormal columns, R is upper triangular.

When to use it
  • Whenever you need a "nice" (orthonormal) basis for a subspace instead of an arbitrary skewed one — e.g. before projecting onto a subspace, or as groundwork for eigenvector/SVD algorithms in Unit 2.
  • For solving least squares (regression) numerically without forming AᵀA — which squares the conditioning and can wreck accuracy when features are nearly collinear. QR is the stable alternative used by real libraries.
  • To orthogonalise correlated features one at a time — removing from each new feature whatever the earlier ones already explain.

How to use it — step by step

  1. Start with independent vectors a, b, c, … Normalise the first: q₁ = a/‖a‖.
  2. For each subsequent vector, subtract its projection onto every q already found: Aⱼ = aⱼ − Σ (qᵢᵀaⱼ)qᵢ (sum over all earlier i).
  3. Normalise the result: qⱼ = Aⱼ/‖Aⱼ‖. If Aⱼ comes out as zero, the original vectors were not actually independent.
  4. Collect the q's as the columns of Q. Compute R = QᵀA — upper triangular by construction.
  5. To solve least squares Ax=b, solve Rx̂ = Qᵀb directly by back-substitution — no need to ever form or invert AᵀA.
Orthonormal basis

qᵢᵀqⱼ = 0 (i≠j), qᵢᵀqᵢ = 1.

Orthogonal matrix Q
QᵀQ = I   ⟹ (square Q)⟹   Qᵀ = Q⁻¹

‖Qx‖ = ‖x‖ — lengths & angles preserved, so no numerical instability is introduced.

Coordinates — no elimination needed
x = Qᵀb,   i.e.   b = Σ (qᵢᵀb) qᵢ
QR factorization
A = QR    Q: orthonormal columns    R: upper triangular, R = QᵀA
Least squares via QR

Normal equations AᵀAx̂=Aᵀb become Rx̂ = Qᵀb — solved by back-substitution, never forming AᵀA (which would square the conditioning and amplify error).
