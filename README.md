# TYN Notes

A personal study-notes site for Semester 3 engineering courses. Each unit is a single self-contained HTML page with a sidebar table of contents, in-page search, and dark mode.

Live: `https://tyn-notes.vercel.app`

## How it works

No build step, no framework, no npm — just plain HTML, CSS, and vanilla JavaScript. Open `index.html` and you're in. The home page shows each subject as a card, and each card links to one page per unit. Every page is fully inlined, so it works offline on its own.

## Run locally

Just open `index.html` in a browser. Or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy

Fully static — deploys to Vercel with zero config.
