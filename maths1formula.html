Unit 1 - Rapid Revision Sheet

Real formulas, each explained in one plain line. For a quick last-minute recap.

1. Row and Column Pictures

A x = b
  • Row way: each equation is a line, answer is where all lines cross.
  • Column way: mix the columns of A to hit target b.
  • Use when: checking why a system has 0, 1, or infinite answers.

2. Gaussian Elimination

multiplier = a / pivot new row = old row - (multiplier x pivot row)
  • Cancel one unknown at a time using the pivot row, then solve bottom to top.
  • Use when: solving a system for actual numbers.

3. Rank and Consistency

rank(A) vs rank(A,b)Answer count
equal, = n1 solution
equal, less than ninfinite solutions
not equal0 solutions
  • Rank = number of useful (non-repeated) equations.
  • Use when: predicting solution count before solving.

4. LU Factorization

A = L x U solve: L c = b, then U x = c
  • L = saved cancel-numbers, U = leftover triangle from elimination.
  • Use when: solving the same A for many different b values.

5. Inverse (Gauss-Jordan)

[A | I] -> [I | inverse of A]
  • Inverse is the matrix version of "1 divided by a number".
  • Use when: you need the inverse itself, not just one solve (otherwise use elimination, it is faster).

6. Vector Spaces and Subspaces

0 in W   u+v in W   c*u in W
  • A valid space stays "closed" when you add items or scale them.
  • Use when: checking if a given set counts as a subspace.

7. Column Space and Null Space

A x = b solvable only if b is in column space of A
  • Column space = every output A can produce. Null space = every input that gives zero.
  • Use when: checking if b is reachable, or why answers are not unique.

8. Four Fundamental Subspaces

  • r = rank. n = number of unknowns. m = number of equations.
  • Use when: needing the full existence/uniqueness picture in one shot.

9. Independence, Basis, Dimension

A c = 0 only when c = 0 -> independent
  • Basis = smallest set that still covers everything (independent + spans).
  • Dimension = number of vectors in that basis.
  • Use when: checking for redundant vectors or features.

10. Linear Transformations

T(c x + d y) = c T(x) + d T(y)
  • Scaling/adding inputs scales/adds outputs the same way, no twisting.
  • Matrix columns = T applied to each basis vector.
  • Use when: turning a rule (rotate, project, reflect) into a matrix.

11. Gram-Schmidt and QR

new vector = old vector - (its part already covered) A = Q x R
  • Removes overlap, then shrinks each vector to length 1.
  • Use when: needing a perpendicular basis, or stable least-squares fitting.
