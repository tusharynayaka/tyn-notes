Unit 1 - Rapid Revision Sheet

Systems of equations, elimination, factorization and vector spaces - each idea explained in one plain line. For a quick last-minute recap.

1. Linear Equations & Systems

a1x1 + a2x2 + ... + anxn = b
  • Homogeneous: all b's are zero (always has the trivial solution x = 0).
  • Non-homogeneous: at least one b is non-zero.
  • Superposition: A(c1x1 + c2x2) = c1(Ax1) + c2(Ax2) - holds only for linear systems.
  • Use when: writing any system in matrix form Ax = b.

2. Row and Column Pictures

A x = b
  • Row way: each equation is a line/plane, answer is where all lines cross.
  • Column way: mix the columns of A (scaled by x, y, ...) to hit target vector b.
  • Intersecting lines → unique solution; parallel → no solution; overlapping → infinite solutions.
  • Use when: visualising why a system has 0, 1, or infinitely many answers.

3. Elementary Row Operations & Echelon Form

Ri → kRi   Ri → Ri + kRj   Ri ↔ Rj
  • Echelon form: pivots step to the right going down, zeros below every pivot.
  • RREF: every pivot scaled to 1, zeros above and below each pivot too.
  • Elementary matrix Eij = identity matrix after one row operation.
  • Use when: reducing a matrix by hand or tracking operations as matrix multiplication.

4. Rank of a Matrix

rank(A) = number of non-zero rows in echelon form
  • Also = max number of linearly independent rows or columns of A.
  • Found via minors: largest order of a non-vanishing minor.
  • Use when: predicting how many "useful" independent equations a system has.

5. Rank, Consistency & Solutions

rank(A) vs rank[A:b]Result
equal, = nunique solution
equal, < ninfinite solutions
not equalno solution (inconsistent)
  • n = number of unknowns; consistent means at least one solution exists.
  • Use when: deciding solvability before actually solving.

6. Gaussian Elimination

[A : b] → [U : c] by row ops, then back-substitute
  • No row exchange → retain first row; first non-zero entry of each row is the pivot.
  • Singular system (det A = 0): no solution or infinitely many solutions.
  • Zero in pivot spot, curable by row exchange → non-singular, full set of pivots recovered.
  • Zero in pivot spot, permanent breakdown → singular, incurable.
  • Use when: solving Ax = b for actual numbers while checking consistency.

7. Elementary Matrices & LU Factorization

Ek ... E2E1 A = U    A = LU
  • L = record of the multipliers used (1's on the diagonal), U = resulting upper triangular matrix.
  • Undo elimination: reverse the sign of the row operation to go back from U to A.
  • Use when: solving the same A for many different b's without repeating elimination each time.

8. LDU Factorization & Permutation Matrices

A = LDU    PA = LU
  • D pulls the pivots onto the diagonal so both L and U end with 1's on their diagonal.
  • If A is symmetric, then U = LT, so A = LDLT.
  • Permutation matrix P = identity matrix with rows reordered; needed when a zero sits in the pivot spot and rows must be swapped.
  • Use when: elimination needs a row swap, or a symmetric factorization is wanted.

9. Inverse of a Matrix (Gauss-Jordan)

[A | I] → [I | A-1]
  • Inverse exists (A non-singular) iff elimination produces n pivots, with or without row exchange.
  • (ABCD)-1 = D-1C-1B-1A-1    (AT)-1 = (A-1)T
  • Use when: you need the inverse itself, not just one solve (otherwise elimination alone is faster).

10. Vector Spaces & Subspaces

0 ∈ W   u+v ∈ W   cu ∈ W
  • Vector space needs both closure conditions plus 8 axioms (commutative, associative, zero vector, inverses, distributive laws).
  • A subspace defined by a homogeneous linear equation is automatically a subspace ("0" always satisfies both addition and scaling).
  • Use when: checking if a given set counts as a (sub)space.

11. Four Fundamental Subspaces & Rank-Nullity

SpaceLives inDimension
column space C(A)Rmr
row space C(AT)Rnr
null space N(A)Rnn - r
left null space N(AT)Rmm - r
  • r = rank(A); n = number of columns; m = number of rows. Rank-Nullity: r + (n - r) = n.
  • Row space and null space are orthogonal complements in Rn (similarly for the other pair in Rm).

12. Independence, Basis, Dimension

c1v1 + c2v2 + ... = 0 ⇒ all ci = 0 (independent)
  • Basis = independent set that also spans the space; dimension = number of vectors in that basis.
  • A free column (no pivot) in echelon form signals dependence among the vectors.
  • Use when: checking for redundant vectors, or finding a basis for a subspace.

13. Linear Transformations

T(cx + dy) = cT(x) + dT(y)
  • Linear transformations always send the origin to the origin: T(0) = 0 (converse not guaranteed).
  • Matrix columns = T applied to each standard basis vector.
  • Use when: turning a rule (rotate, project, reflect, stretch) into a matrix.

14. Special Transformation Matrices (R2)

stretch: (x,y) → (cx,cy)  |  rotate 90°: (x,y) → (-y,x) reflect on y=x: (x,y) → (y,x)  |  project on x-axis: (x,y) → (x,0)
  • Stretching/scaling matrices expand or contract the whole space by factor c.
  • Rotation and reflection matrices are invertible; projection matrices are not (they collapse a dimension).
  • Use when: recognising or building the matrix behind a geometric operation.
