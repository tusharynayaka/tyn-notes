Length, Inner Product & Norms

What it is

The length ‖x‖ of a vector generalises the Pythagorean hypotenuse to n dimensions, and the inner product (dot product) xᵀy = x₁y₁+…+xₙyₙ is the single number that carries both length and angle information. Setting y = x recovers the length: xᵀx = ‖x‖². Two vectors are orthogonal exactly when xᵀy = 0.

When to use it
  • Whenever you need to measure "how similar" two vectors, embeddings, or feature rows are — the inner product, normalised into a cosine, is the most-used operation in machine learning.
  • To test perpendicularity of any two vectors in any dimension, instantly, without geometry.
  • To decide which norm (L1, L2, L∞) suits a modelling goal — this choice underlies ridge regression, the lasso, and robustness arguments.

How to use it — step by step

  1. To find a length: square every component, add them, take the square root — ‖x‖ = √(xᵀx).
  2. To find the inner product: multiply corresponding components of x and y and add — xᵀy = Σxᵢyᵢ.
  3. To test orthogonality: compute xᵀy. If it is exactly 0, the vectors are perpendicular; if positive the angle is under 90°, if negative it is over 90°.
  4. To get a unit vector pointing the same way as x, divide by its own length: x/‖x‖.
Length & inner product
‖x‖² = xᵀx = x₁²+…+xₙ²    xᵀy = x₁y₁+…+xₙyₙ

The zero vector is the only vector of length zero, and the only vector orthogonal to itself.

Family of norms
‖x‖₁ = Σ|xᵢ|    ‖x‖₂ = √(Σxᵢ²)    ‖x‖∞ = max|xᵢ|

Unless stated otherwise ‖x‖ means the Euclidean ‖x‖₂ — the only one built from an inner product, so the only one that carries a notion of angle.

Orthogonal sets are independent

If non-zero vectors v₁,…,vₖ are mutually orthogonal, they are automatically linearly independent (take the inner product of c₁v₁+…+cₖvₖ=0 with each vᵢ in turn; every cross term vanishes, forcing cᵢ=0). The converse fails — independent vectors need not be orthogonal, e.g. (2,1) and (1,2) in R².

Cosine & the Schwarz inequality

cos θ = xᵀy/(‖x‖‖y‖), and since |cos θ| ≤ 1 this gives |xᵀy| ≤ ‖x‖‖y‖ — equality only when x and y are parallel. This is the cosine-similarity formula used everywhere to compare embeddings.

Orthogonal Subspaces & Complements

What it is

Two subspaces V, W are orthogonal if every vector of V is perpendicular to every vector of W. The orthogonal complement V⊥ is the (stronger) set of all vectors orthogonal to V. The Fundamental Theorem of Orthogonality says the four fundamental subspaces of Unit 1 are complementary pairs: row space ⊥ nullspace in Rⁿ, column space ⊥ left nullspace in Rᵐ.

When to use it
  • To decide solvability "backwards": Ax=b is solvable exactly when b ⊥ every y with yᵀA=0 — often far fewer conditions to check than finding C(A) directly.
  • To split any vector x uniquely into a row-space part and a nullspace part, x = xᵣ + xₙ — the geometric root of least squares.
  • To reason about redundant/uncorrelated features: after centring, orthogonal columns are exactly uncorrelated features.

How to use it — step by step

  1. To find a vector orthogonal to a set of given vectors, set up the equations "(unknown)·(each given vector) = 0" and solve.
  2. To find N(A)⊥ (= row space) or C(A)⊥ (= left nullspace), it is enough to describe the space using A itself — no extra computation is needed.
  3. To split x = xᵣ + xₙ: find a basis for N(A) (or the row space), project x onto that line/subspace to get xₙ, then xᵣ = x − xₙ.
Fundamental theorem of orthogonality
N(A) = C(Aᵀ)⊥    N(Aᵀ) = C(A)⊥

dim V + dim V⊥ = n always; V⊥⊥ = V. In R³ a plane can never be orthogonal to a plane — only lines can be orthogonal to lines or to planes.

Key fact

Every x splits uniquely as x = xᵣ + xₙ (row space + nullspace). A destroys the nullspace part and carries the row space part one-to-one onto the column space — nothing ever lands in the left nullspace.

Orthogonal Projections

What it is

Given a point b and a subspace S, the projection p is the point of S closest to b; the key fact is purely geometric — the error e = b − p must be perpendicular to S. Projections range from onto a single line up to onto the whole column space of a matrix.

When to use it
  • Any time a system Ax=b has no exact solution and you need the closest achievable answer.
  • To split a vector into "the part a model can explain" (p, in C(A)) and "the part it cannot" (e, in the left nullspace) — exactly the logic of regression residuals.
  • To build a rank-1 or rank-r matrix that carries out this projection automatically, reusable for many b's.

How to use it — step by step

  1. Onto a line through a: the error aᵀ(b − x̂a)=0 gives x̂ = aᵀb/aᵀa, so p = x̂a and the projection matrix is P = aaᵀ/aᵀa.
  2. Onto the column space of A (m > n, independent columns): solve the normal equations AᵀAx̂ = Aᵀb for x̂, then p = Ax̂; the projection matrix is P = A(AᵀA)⁻¹Aᵀ.
  3. Verify e = b − p is perpendicular to every column of A (equivalently Aᵀe = 0) — this is the defining check of every projection.
  4. Use I − P to project onto the orthogonal complement (the left nullspace) in one step: (I−P)b = e.
Projection onto a line
x̂ = aᵀb/aᵀa    p = x̂a    P = aaᵀ/aᵀa

Rank 1; scaling a changes nothing. If a is already a unit vector, P = aaᵀ.

Projection onto a subspace — normal equations
AᵀA x̂ = Aᵀb    x̂ = (AᵀA)⁻¹Aᵀb    p = A x̂ = A(AᵀA)⁻¹Aᵀ b

Needs independent columns of A so that AᵀA is invertible — AᵀA has the same nullspace as A.

The two defining properties

Every projection matrix satisfies P² = P (projecting twice changes nothing) and Pᵀ = P (symmetric). Conversely any symmetric idempotent matrix is a projection. trace(P) = rank(P) = dimension of the subspace projected onto.

Least Squares Approximation

What it is

When Ax=b is overdetermined (more equations than unknowns) and has no exact solution, least squares finds the x̂ that minimises ‖Ax−b‖ — equivalently, the x̂ whose Ax̂ is the projection of b onto C(A). This is exactly linear regression.

When to use it
  • Fitting a straight line, plane, or any linear model to noisy measurements — curve fitting, regression, surveying.
  • Any time there are more data points/equations than parameters and an exact fit is impossible.
  • Weighted least squares when some measurements should be trusted more than others.

How to use it — step by step

  1. Set up A (design matrix of the model, e.g. columns 1 and t for a line C+Dt) and b (the observed values).
  2. Compute AᵀA and Aᵀb, then solve the normal equations AᵀAx̂ = Aᵀb for x̂ (invert the 2×2/3×3 system directly, or use Cramer's Rule).
  3. Compute the fitted values p = Ax̂ and the residual e = b − p.
  4. Always verify: e must be perpendicular to every column of A (Aᵀe = 0) — this is the proof the fit is correct.
  5. For weighted least squares, replace the normal equations with AᵀWA xw = AᵀWb, where W is the (diagonal) weight matrix.
Normal equations (unweighted)
AᵀA x̂ = Aᵀb

Obtained simply by left-multiplying the unsolvable Ax=b by Aᵀ.

Weighted least squares
AᵀW A xw = AᵀW b

W trusts some equations more than others; ordinary least squares is the special case W = I.

Straight-line fitting

To fit b = C + Dt to points (t₁,b₁),…,(tₘ,bₘ): A has columns (1,…,1) and (t₁,…,tₘ); solve AᵀA[C;D]=Aᵀb. The fitted line always passes through the centroid point (t̄, b̄) — a direct consequence of the first normal equation.

Where the residual lives (the four subspaces, again)

e = b − Ax̂ always lies in N(Aᵀ), the left nullspace of A — it is exactly the piece of b orthogonal to every column, i.e. orthogonal to C(A).

AI/DS reading

P = A(AᵀA)⁻¹Aᵀ is the statistician's "hat matrix" (it puts the hat on b); its diagonal entries are leverages and trace(P)=rank is the effective number of parameters. Collinear features make AᵀA singular — ridge regression fixes this via (AᵀA+λI)x̂=Aᵀb. Forming AᵀA squares the conditioning of the problem, which is why real solvers use the QR factorization instead (next topic).

Gram–Schmidt & QR Factorization

What it is

Gram–Schmidt turns any independent set of vectors a, b, c, … into an orthonormal set q₁, q₂, q₃, … by subtracting off, from each new vector, whatever the earlier q's already explain, then normalising. Recording the process as a matrix equation gives A = QR: Q has orthonormal columns, R is upper triangular.

When to use it
  • Whenever you need a "nice" orthonormal basis for a subspace instead of an arbitrary skewed one — the standard groundwork for eigenvector/SVD algorithms.
  • To solve least squares numerically without forming AᵀA (which squares the conditioning) — solve Rx̂ = Qᵀb by back-substitution instead.
  • To extend a partial orthonormal set (e.g. finding a third column to complete an orthogonal matrix) or verify orthogonality of a set of vectors.

How to use it — step by step

  1. Normalise the first vector: q₁ = a/‖a‖.
  2. For each next vector, subtract its projection onto every q already found: B = b − (bᵀq₁)q₁, then C = c − (cᵀq₁)q₁ − (cᵀq₂)q₂, and so on.
  3. Normalise the result at each step: qⱼ = (that leftover vector)/‖leftover‖. If the leftover is zero, the original vectors were not independent.
  4. Collect the q's as columns of Q. Compute R = QᵀA — upper triangular by construction, with the norms used in step 1–3 appearing on its diagonal.
  5. To solve least squares Ax=b: solve Rx̂ = Qᵀb directly by back-substitution.
Gram–Schmidt step
Aⱼ = aⱼ − Σᵢ<ⱼ (qᵢᵀaⱼ) qᵢ    qⱼ = Aⱼ/‖Aⱼ‖

Subtract the components already captured by earlier q's, then normalise.

QR factorization
A = QR    QᵀQ = I    R upper triangular, R = QᵀA

For n vectors with m components: A is m×n, Q is m×n (orthonormal columns), R is n×n upper triangular.

Least squares via QR

The normal equations AᵀAx̂=Aᵀb become Rx̂ = Qᵀb, solved by back-substitution — never forming AᵀA, so no loss of numerical accuracy.

Completing an orthogonal matrix

Given some orthonormal columns, a further column must be a unit vector orthogonal to all the others — solve the resulting homogeneous system, normalise, and note the only remaining freedom is an overall sign flip. Since Q is square with orthonormal columns, QᵀQ=I ⟹ QQᵀ=I too, so the rows become orthonormal automatically.

Eigenvalues & Eigenvectors

What it is

Instead of Ax=b, we now ask Ax = λx: for which special directions x does multiplying by A only stretch or shrink the vector, never turn it aside? λ is the eigenvalue, x the eigenvector. This underlies solutions of du/dt=Au (pure exponential solutions eλtx) and every method that "finds structure" in data.

When to use it
  • To solve coupled linear differential/difference equations — each eigenvalue gives a growth or decay rate, each eigenvector the direction it happens in.
  • To judge the stability of a repeated process (Markov chains, PageRank, RNN gradients, iterative solvers) — the largest |λ| eventually dominates.
  • Wherever "the direction of greatest variance/spread" is needed — this is exactly what PCA computes on a covariance matrix.

How to use it — step by step

  1. Form det(A − λI) = 0, the characteristic polynomial of degree n — its roots are the n eigenvalues (with repetition).
  2. For each eigenvalue λ, solve (A − λI)x = 0 for a non-zero x (its nullspace) — this is the eigenvector, unique only up to scaling.
  3. Sanity-check: sum of eigenvalues = trace(A); product of eigenvalues = det(A).
  4. For a triangular matrix, read the eigenvalues straight off the diagonal — no computation needed.
Characteristic equation
(A − λI)x = 0  ⟹  det(A − λI) = 0

Eigenvectors are never unique — the whole eigenspace (nullspace of A−λI) consists of eigenvectors for that λ.

Trace & determinant checks (2×2 shortcut)
λ₁+λ₂+…+λₙ = trace(A)    λ₁λ₂…λₙ = det(A)    λ = [tr ± √(tr²−4det)]/2
Rule Statement
Powers Aᵏx = λᵏx — λᵏ is an eigenvalue of Aᵏ, same eigenvector
Inverse if λ≠0, A⁻¹x = (1/λ)x
Shift eigenvalues of A−cI are λ−c; eigenvectors unchanged
Transpose A and Aᵀ share eigenvalues (not eigenvectors)
Projection P²=P ⟹ eigenvalues are only 0 or 1
Singular A singular ⟺ λ=0 is an eigenvalue
Cayley–Hamilton

Every matrix satisfies its own characteristic equation: if det(A−λI)=λⁿ+c₁λⁿ⁻¹+…+cₙ, then Aⁿ+c₁Aⁿ⁻¹+…+cₙI=0. This reduces high powers of A to low ones, and gives A⁻¹ algebraically — for a 2×2 with λ²−λ−2=0, A⁻¹=½(A−I).

Warning

Pivots, diagonal entries, and eigenvalues are three different things in general — they coincide only for triangular matrices. Elimination changes eigenvalues, which is exactly why elimination cannot be used to find them.

Diagonalization of Matrices

What it is

If an n×n matrix A has n independent eigenvectors, putting them as columns of S and the eigenvalues as diag(λ₁,…,λₙ)=Λ gives S⁻¹AS = Λ, equivalently A = SΛS⁻¹. In the eigenvector coordinates, A is nothing but n independent scalings.

When to use it
  • Computing high powers Aᵏ cheaply: Aᵏ = SΛᵏS⁻¹ turns matrix multiplication into scalar exponentiation.
  • Solving linear recurrences/differential equation systems in closed form.
  • Deciding long-run stability of an iterative process: Aᵏ → 0 exactly when every |λ| < 1.

How to use it — step by step

  1. Find all eigenvalues and a full set of eigenvectors (previous topic).
  2. Check there are n independent eigenvectors — guaranteed automatically if all n eigenvalues are distinct.
  3. Place the eigenvectors as the columns of S (any order), and the corresponding eigenvalues in the same order on the diagonal of Λ.
  4. Then A = SΛS⁻¹. Use Aᵏ = SΛᵏS⁻¹ and A⁻¹ = SΛ⁻¹S⁻¹ for powers/inverses.
Diagonalization
AS = SΛ    S⁻¹AS = Λ    A = SΛS⁻¹

S is never unique — eigenvectors can be rescaled freely. Order of columns in S and diagonal of Λ must match.

Powers
Aᵏ = S Λᵏ S⁻¹

Aᵏ → 0 as k→∞ exactly when every |λᵢ| < 1.

When it fails

Diagonalization needs enough eigenvectors, not non-zero eigenvalues — the two properties are unrelated. A repeated eigenvalue (algebraic multiplicity p) is diagonalizable only if its eigenspace also has dimension p (geometric multiplicity = p, i.e. rank(A−λI)=n−p). Classic failure: [0 1; 0 0] has λ=0 twice but only one eigenvector.

Distinct eigenvalues ⟹ independent eigenvectors

If λ₁,…,λₖ are all different, their eigenvectors are automatically linearly independent. So any matrix with n distinct eigenvalues can always be diagonalized — the typical, easy case.

Symmetric matrices are special

When A is symmetric, eigenvectors can always be chosen orthonormal, so S becomes an orthogonal matrix Q with S⁻¹=Sᵀ. This is the spectral theorem A = QΛQᵀ — it is what makes PCA on a covariance matrix both possible and numerically safe, and it is the seed of the SVD.

Quadratic Forms & Covariance Matrices

What it is

For a symmetric matrix A, xᵀAx is a pure quadratic form — no linear or constant terms. Whether xᵀAx is always positive (positive definite), always non-negative (positive semidefinite), always negative, or mixed (indefinite) decides whether a stationary point is a bowl, valley, dome, or saddle. Any unsymmetric A can be replaced by the symmetric Â=(A+Aᵀ)/2 without changing xᵀAx.

When to use it
  • Classifying stationary points of a multivariable function (the matrix of second partial derivatives, the Hessian).
  • Recognising that a covariance matrix is always positive semidefinite, and exactly when it is strictly positive definite (no redundant/collinear feature).
  • Confirming AᵀA is invertible for least squares (positive definite ⟺ independent columns of A).

How to use it — the 2×2 test, then general

  1. Write f = ax²+2bxy+cy² and its matrix A=[a b; b c].
  2. Complete the square: ax²+2bxy+cy² = a(x+(b/a)y)² + ((ac−b²)/a)y².
  3. f is positive definite ⟺ a > 0 and ac > b². (Positive coefficients alone are never enough.)
  4. For a general symmetric matrix, recover it from a quadratic form by halving every cross-coefficient and placing it symmetrically off the diagonal.
Quadratic form ↔ symmetric matrix
xᵀA x = Σᵢ Σⱼ aᵢⱼxᵢxⱼ = a₁₁x₁² + 2a₁₂x₁x₂ + …
Type 2×2 condition Eigenvalues Graph
Positive definite a>0, ac>b² all λ>0 bowl
Positive semidefinite a≥0, ac=b² all λ≥0, some λ=0 valley
Negative definite a<0, ac>b² all λ<0 dome
Indefinite ac<b² mixed signs saddle

Why AᵀA is always positive semidefinite

For any matrix A, xᵀ(AᵀA)x = (Ax)ᵀ(Ax) = ‖Ax‖² ≥ 0. It is strictly positive definite exactly when N(A)={0}, i.e. the columns of A are independent. This is the reason AᵀA was invertible in the normal equations.

The covariance matrix
S = (1/(n−1)) YᵀY,   Y = centred data

(i,i) entry = variance of feature i; (i,j) entry = covariance of features i,j. S is always positive semidefinite (cᵀSc = ‖Yc‖²/(n−1) ≥ 0 is the variance of the combined feature Yc), and positive definite exactly when no feature is an exact linear combination of the others.

Key fact for PCA

S is symmetric, so its eigenvalues are real and non-negative and its eigenvectors can be chosen orthonormal. Along a unit eigenvector u, uᵀSu=λ is the variance of the data in that direction — the largest eigenvalue is the direction of greatest spread.

Tests for Positive Definiteness

What it is

Four completely equivalent tests decide whether a real symmetric matrix A is positive definite, and a fifth (A=RᵀR) connects the idea to least squares and prepares the ground for the SVD.

When to use it
  • Checking positive definiteness of a matrix quickly by hand (determinant test) or as software does it internally (pivot test).
  • Proving general theorems about positive definite matrices (eigenvalue test is most convenient for proofs).
  • Producing a "square root" factor R of a positive definite matrix — Cholesky decomposition, used in simulation and optimisation.

How to use it — step by step

  1. Form the leading principal submatrices A₁, A₂, …, Aₙ=A (the top-left k×k blocks).
  2. Compute det(A₁), det(A₂), …, det(Aₙ). If all are strictly positive, A is positive definite (test III).
  3. Equivalently, run elimination without row exchanges; if every pivot is positive, A is positive definite (test IV) — this is what a computer actually does.
  4. To classify a semidefinite/indefinite case, check where a leading determinant first becomes zero or negative.
Four equivalent tests (Statement 6B)
(I) xᵀAx>0 ∀x≠0   (II) all λᵢ>0   (III) all leading det(Aₖ)>0   (IV) all pivots dₖ>0

Every diagonal entry of a PD matrix must itself be positive, but that alone never suffices.

The fifth test
A is PD  ⟺  A = RᵀR for some R with independent columns

Cholesky: A=LDLᵀ=(L√D)(√D Lᵀ), so R=√D Lᵀ. From eigenvalues: A=QΛQᵀ=(Q√Λ)(√Λ Qᵀ), so R=√Λ Qᵀ, or the symmetric square root R=Q√Λ Qᵀ. R is never unique.

Why the tests agree, in one line each

I⟺II via xᵀAx=Σcᵢ²λᵢ in the eigenvector basis. I⟹III by restricting x to the first k coordinates. III⟹IV since pivot dₖ=det(Aₖ)/det(Aₖ₋₁). IV⟹I via A=LDLᵀ, so xᵀAx = Σdᵢ(Lᵀx)ᵢ² — elimination and completing the square are the same operation.

Singular Value Decomposition (SVD)

What it is

Every matrix — square or rectangular, singular or not — factors as A = UΣVᵀ: an orthogonal matrix, times a diagonal matrix of non-negative singular values σ₁≥σ₂≥…≥σᵣ>0, times another orthogonal matrix. U holds eigenvectors of AAᵀ, V holds eigenvectors of AᵀA, and the whole factorization is the single statement Avⱼ = σⱼuⱼ.

When to use it
  • Getting orthonormal bases for all four fundamental subspaces of any matrix in one stroke.
  • Data compression / low-rank approximation — images, recommender systems, latent semantic analysis.
  • Numerically stable least squares and the pseudoinverse, when AᵀA is singular or ill-conditioned.
  • Separating "rotation" from "stretching" in a linear map (polar decomposition) — robotics, mechanics.

How to use it — step by step

  1. Compute AᵀA (n×n, symmetric PSD); find its eigenvalues σᵢ² and unit eigenvectors vᵢ — these are the columns of V, ordered by decreasing σᵢ.
  2. For each σⱼ>0, get the matching left singular vector via uⱼ = Avⱼ/σⱼ — never guess signs, always fix them from Avⱼ=σⱼuⱼ.
  3. For σⱼ=0 (j>r), fill in the remaining uⱼ's and vⱼ's by orthogonality (they span the left nullspace / nullspace).
  4. Assemble Σ as an m×n diagonal matrix (or r×r for the reduced/thin form) holding the σ's.
  5. Check: A = σ₁u₁v₁ᵀ + … + σᵣuᵣvᵣᵀ (sum of rank-one pieces) should reproduce A.
The factorization
A = UΣVᵀ    AAᵀ=UΣΣᵀUᵀ    AᵀA=VΣᵀΣVᵀ    Avⱼ = σⱼuⱼ

A matrix of rank r has exactly r non-zero singular values, since N(AᵀA)=N(A) forces λ=0 to have multiplicity n−r.

Subspace Basis
Column space C(A) first r columns of U
Left nullspace N(Aᵀ) last m−r columns of U
Row space C(Aᵀ) first r columns of V
Nullspace N(A) last n−r columns of V
Rank-one expansion & best approximation (Eckart–Young)
A = σ₁u₁v₁ᵀ+…+σᵣuᵣvᵣᵀ    Aₖ = Σᵢ₌₁ᵏ σᵢuᵢvᵢᵀ is the best rank-k approximation

‖A−Aₖ‖² = σₖ₊₁²+…+σᵣ² (total squared error); ‖A−Aₖ‖₂ = σₖ₊₁ (worst-case stretching). Nothing else of rank k can do better.

Effective rank & condition number

Singular values are stable where pivots are not: count σ's above a chosen tolerance for the effective rank. condition number = σₘₐₓ/σₘᵢₙ measures how badly errors are amplified when solving a system — large condition number signals multicollinearity / numerical trouble.

Polar decomposition
A = QS,   Q = UVᵀ (orthogonal),   S = VΣVᵀ (symmetric PSD, S²=AᵀA)

Separates rotation (Q) from stretching (S) — used in mechanics and robotics.

Pseudoinverse & shortest least-squares solution
A⁺ = VΣ⁺Uᵀ    x⁺ = A⁺b (shortest solution, lies in the row space)

Σ⁺ inverts each non-zero σᵢ and leaves zeros alone. Special cases: independent columns ⟹ A⁺=(AᵀA)⁻¹Aᵀ; independent rows ⟹ A⁺=Aᵀ(AAᵀ)⁻¹.

Principal Component Analysis (PCA)

What it is

PCA is an orthogonal transformation that converts correlated features into uncorrelated principal components, found greedily: the first component is the direction of maximum variance, the second is the max-variance direction orthogonal to the first, and so on. It is exactly the SVD of the centred data matrix — no separate machinery is needed.

When to use it
  • Compressing many correlated features into a handful of uncorrelated ones while keeping most of the variance (signal).
  • Fighting multicollinearity in regression, since the resulting components are uncorrelated by construction.
  • Visualising high-dimensional data in 2 or 3 dimensions, or as a preprocessing step before another model to relieve overfitting.

How to use it — the six-step procedure

  1. Start with the data matrix X (choose a layout: features×samples or samples×features, and be consistent).
  2. Centre it: subtract each row's (or column's) own mean, so X̃ has every row (or column) summing to zero.
  3. Take the SVD: X̃ = UΣVᵀ.
  4. Read off the principal directions — with features in rows, they are the columns of U.
  5. Read off the variance explained by each direction: σᵢ²/(n−1).
  6. Project: Z = UᵀX̃ gives every sample's coordinates in principal-component space; keep only the first k columns of U for a reduced representation.
Why the SVD delivers PCA
S = X̃X̃ᵀ/(n−1) = U[ΣΣᵀ/(n−1)]Uᵀ

Substituting X̃=UΣVᵀ into S makes every V cancel (VᵀV=I) — U is exactly the eigenvector matrix of the covariance matrix, with eigenvalues σᵢ²/(n−1). Working from the SVD avoids ever forming S, which would square the condition number.

Variance retained by the first k components
(λ₁+…+λₖ)/(λ₁+…+λₘ),   λᵢ = σᵢ²/(n−1)

Keep the smallest k reaching a chosen threshold (commonly 90–95%), or use the "elbow" where the eigenvalue curve flattens.

Feature selection vs. feature extraction

Selection keeps a subset of original features (interpretable, meaning preserved). Extraction (PCA) builds new features as blends of all the old ones — compact and uncorrelated, but harder to interpret. PCA is unsupervised (ignores any target/label) and is not scale-invariant: standardise features measured in different units before running it (equivalent to using the correlation matrix instead of the covariance matrix).

Dimensionality Reduction

What it is

Real high-dimensional data (images, text, genomics) typically occupies a far smaller "thin sheet" than the space it's recorded in. Dimensionality reduction re-describes the data inside that smaller sheet, and the SVD's rank-k truncation is the theorem that makes this rigorous and optimal.

When to use it
  • Compressing images, audio, or any large matrix while keeping the visually/statistically important structure (eigenfaces, latent semantic analysis).
  • Filling in missing entries of a user–item matrix (recommender systems) via low-rank structure.
  • Whenever the number of features approaches or exceeds the number of samples, to avoid guaranteed overfitting.

How to use it — step by step

  1. Compute (or estimate) the singular values of the data/image matrix.
  2. Decide a target k either by a storage budget, an energy/variance threshold (e.g. 95% of Σσᵢ²), or the "elbow" of the singular-value plot.
  3. Form Aₖ = UₖΣₖVₖᵀ using only the first k singular triples — this is provably the best rank-k approximation of A.
  4. If the covariance-style matrix (e.g. PPᵀ for stacked images) is too large to diagonalize directly, diagonalize the much smaller PᵀP instead and recover v = Pu — same non-zero eigenvalues, far cheaper.
Storage cost & break-even
cost(Aₖ) = k(m+n+1) numbers    worthwhile when k < mn/(m+n+1)

For a 512×512 image, truncation saves space up to about k≈255; k=20 already gives roughly 12.8:1 compression.

Error of the best rank-k fit
‖A−Aₖ‖² = σₖ₊₁²+…+σᵣ²    ‖A−Aₖ‖₂ = σₖ₊₁

Exactly what was discarded — no other rank-k matrix does better (Eckart–Young theorem).

The PᵀP trick

If P (m×N, m huge, N samples) is too big for PPᵀ to be practical, diagonalize PᵀP (N×N, small) instead: if PᵀPu=λu with λ≠0, then P u is an eigenvector of PPᵀ with the same eigenvalue. This makes eigenface-style computations on thousands of pixels feasible using only as many eigenvectors as there are images.

Filtering is not reduction

An image convolution/filter (e.g. averaging or sharpening kernel) is linear but maps an m×n image to another m×n image — the dimension is unchanged. Truncating the SVD genuinely moves the data to a smaller space. Keep the distinction: filtering changes what the data looks like; reduction changes how much of it there is.

Question Answer
Best rank-k fit? Aₖ = UₖΣₖVₖᵀ — truncate the rank-one expansion
How large is the error? Σ of discarded σᵢ², or σₖ₊₁ in the 2-norm
How many components? smallest k reaching 90–99% of Σσᵢ² (energy), or the elbow
Huge covariance matrix? use PᵀP instead of PPᵀ — same non-zero eigenvalues
Which method? PCA if unsupervised, LDA if class labels are known
