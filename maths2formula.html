Unit 2 - Rapid Revision Sheet

Real formulas, each explained in one plain line. For a quick last-minute recap.

1. Length, Inner Product, Norms

length of x = sqrt(x . x) x . y = x1y1 + x2y2 + ... + xnyn
  • Length = square root of a vector dotted with itself.
  • Dot product = multiply matching entries and add them up.
  • If x . y = 0, the two vectors are perpendicular (orthogonal).
  • Use when: measuring similarity, angle, or perpendicularity between vectors.

2. Orthogonal Subspaces

null space of A = perpendicular to row space of A left null space of A = perpendicular to column space of A
  • Every vector splits into a "row space part" plus a "null space part".
  • Use when: deciding if A x = b is solvable, or splitting a vector cleanly in two.

3. Orthogonal Projections

onto a line: x_hat = (a . b) / (a . a), p = x_hat x a onto a subspace: A^T A x_hat = A^T b, p = A x_hat
  • Projection = the closest point in a line or subspace to a given point.
  • Projecting twice does nothing extra (once you land there, you stay there).
  • Use when: a target point is not exactly reachable and you want the nearest reachable point.

4. Least Squares Approximation

A^T A x_hat = A^T b error = b - A x_hat, always perpendicular to columns of A
  • Used when A x = b has no exact answer (more equations than unknowns).
  • The leftover error is always perpendicular to your data columns - this is how you check your work.
  • Use when: fitting a best-fit line or plane to noisy data.

5. Gram-Schmidt and QR

new vector = old vector - (its part already covered) A = Q x R
  • Removes overlap between vectors, then shrinks each one to length 1.
  • Q = the clean perpendicular version of A, R keeps track of what was removed.
  • Use when: needing a clean basis, or solving least squares without losing accuracy.

6. Eigenvalues and Eigenvectors

A x = lambda x det(A - lambda I) = 0
  • Eigenvector = a special direction that A only stretches, never turns.
  • Eigenvalue (lambda) = how much it gets stretched by.
  • Sum of eigenvalues = trace(A). Product of eigenvalues = det(A).
  • Use when: understanding repeated processes, growth/decay, or long-term stability.

7. Diagonalization

A = S x Lambda x S^-1 A^k = S x Lambda^k x S^-1
  • Rewrites A as "switch to eigenvector view, scale simply, switch back".
  • Needs enough independent eigenvectors (n of them for an n by n matrix).
  • Use when: computing big powers of A, or solving repeated/step-by-step systems.

8. Quadratic Forms and Covariance

x^T A x = sum of aij times xi times xj covariance matrix S = (1 / (n-1)) x Y^T Y
  • Tells you if a matrix always gives a positive, negative, or mixed result.
  • Covariance matrix shows how spread out each feature is, and how features move together.
  • Use when: classifying a stationary point, or checking if data features are correlated.

9. Positive Definite Tests

Test Condition
direct x^T A x > 0 for every x
eigenvalues every eigenvalue > 0
determinants every leading determinant > 0
pivots every pivot > 0
  • Four different ways to check the same thing - pick whichever is quickest to compute.
  • Use when: confirming a matrix is safe to treat like a "positive number" (e.g. before inverting it).

10. Singular Value Decomposition (SVD)

A = U x Sigma x V^T A v = sigma x u
Space Comes from
column space first r columns of U
left null space rest of U
row space first r columns of V
null space rest of V
  • Works for ANY matrix, even rectangular ones (unlike plain eigenvalues).
  • Singular values are always zero or positive, and rank how "important" each direction is.
  • Use when: compressing data, or finding all four fundamental subspaces at once.

11. Principal Component Analysis (PCA)

center the data, then take its SVD variance kept by direction i = sigma_i^2 / (n-1)
  • PCA is really just: subtract the mean, then run SVD.
  • The new directions are uncorrelated and ranked by how much information they carry.
  • Use when: turning many correlated features into a few important, clean ones.

12. Dimensionality Reduction

keep only the top k pieces of the SVD sum worth it when k < (m x n) / (m + n + 1)
  • Keeping only the biggest pieces gives the best possible approximation of the original data.
  • Use when: saving storage or computation while keeping most of the important information.
