Unit 2 - Rapid Revision Sheet

Orthogonality, projections, eigen-decomposition and SVD - each idea explained in one plain line. For a quick last-minute recap.

1. Norm, Dot Product & Orthogonality

||x||2 = xTx    xTy = 0 ⇒ orthogonal
  • Norm = length of a vector; the zero vector is the only vector with norm 0.
  • xTy = ||x|| ||y|| cosθ; angle < 90° gives a positive dot product, > 90° gives negative.
  • The zero vector is orthogonal to every other vector, including itself.
  • Use when: checking if two vectors meet at a right angle.

2. Orthogonal Subspaces & Fundamental Theorem

N(A) = C(AT)⊥ in Rn    N(AT) = C(A)⊥ in Rm
  • Two subspaces S, T are orthogonal if xTy = 0 for every x in S, y in T.
  • Every Ax lands in C(A); the null-space part of x is annihilated (sent to 0), the row-space part maps into the column space.
  • Ax = b is solvable iff yTb = 0 whenever yTA = 0 (b is orthogonal to the left null space).
  • Use when: splitting Rn into its row-space and null-space pieces, x = xr + xn.

3. Orthogonal Complement

V⊥ = { x : xTv = 0  ∀ v ∈ V }
  • The orthogonal complement of a subspace V is unique; if S, T are complements in Rn then dim S + dim T = n.
  • To find it: solve the homogeneous system whose rows are the given spanning vectors.
  • Use when: finding all vectors perpendicular to a given plane/row space, or splitting a vector x = xr + xn.

4. Orthonormal Bases & Orthogonal Matrix Q

QTQ = I    QT = Q-1
  • Orthonormal vectors: mutually perpendicular AND each of unit length.
  • Q with orthonormal columns preserves length and angle: (Qx)T(Qy) = xTy.
  • If Q is square, x̂ = QTb solves Qx = b directly (no elimination needed).
  • Use when: simplifying projections or solving systems with a nice orthonormal basis.

5. Gram-Schmidt Process

q1 = a / ||a||    B = b - (q1Tb)q1,   q2 = B / ||B||
  • Repeatedly subtract from each new vector the component already covered by earlier q's, then normalise.
  • For a third vector c: subtract its q1 and q2 components before normalising to get q3.
  • Use when: converting any independent set of vectors into an orthonormal basis.

6. QR Factorization

A = QR    R = QTA (upper triangular)    R x̂ = QTb
  • Columns of Q come from Gram-Schmidt on the columns of A; R records the dot products used to build each q.
  • R is upper triangular because qi is built using only a1 ... ai (never later columns).
  • Use when: Ax = b is not solvable directly, or for numerically stable least-squares.

7. Projections & Projection Matrix

p = (aTb / aTa) a    P = aaT / aTa  (rank 1)
  • p is the point on the line through a closest to b; the error e = b - p is orthogonal to a.
  • A projection matrix is symmetric and idempotent: Pn = P for n = 1, 2, 3, ...
  • General subspace projection: P = A(ATA)-1AT, and x̂ = (ATA)-1ATb.
  • Use when: finding the closest point in a subspace to a given vector.

8. Least Squares & Normal Equations

ATA x̂ = ATb
  • Used when Ax = b is inconsistent; minimises the total squared error E2 = Σ (aix - bi)2.
  • The error vector e = b - Ax̂ is orthogonal to every column of A (it lies in the left null space).
  • Fitting a line b = C + Dt: build the normal equations from the data points and solve for C, D.
  • Use when: no exact solution exists but you need the "best fit" answer.

9. Eigenvalues & Eigenvectors

Ax = λx    det(A - λI) = 0
  • x is an eigenvector (nonzero) of A if Ax is just a scaled version of x; λ is the eigenvalue.
  • det(A - λI) = 0 is the characteristic equation; its roots are the eigenvalues.
  • Trace (sum of the diagonal) = sum of the eigenvalues; det(A) = product of the eigenvalues.
  • Shifted matrix A - cI has the same eigenvectors as A, with every eigenvalue shifted by -c.
  • Use when: finding directions a matrix only stretches, never rotates.

10. Diagonalization & Matrix Powers

A = SΛS-1    An = SΛnS-1
  • S = matrix of eigenvectors (columns), Λ = diagonal matrix of eigenvalues; needs n independent eigenvectors.
  • Distinct eigenvalues always give independent eigenvectors, so A is always diagonalizable in that case.
  • Fractional/negative powers (e.g. A1/2) are found the same way, applying the power to Λ only.
  • Use when: computing high powers of A quickly, or solving recurrences/systems of ODEs.

11. Positive Definiteness & Quadratic Forms

f(x) = xTAx  (A symmetric)
  • Positive-definite tests (any one confirms it): all eigenvalues > 0; all pivots > 0; all leading principal minors > 0 (Sylvester's criterion).
  • Positive definite ⇒ xTAx > 0 for every nonzero x; negative definite ⇒ always < 0; indefinite ⇒ mixed signs.
  • Semidefinite allows zero: xTAx ≥ 0 (positive semidefinite) or ≤ 0 (negative semidefinite).
  • Use when: checking if a symmetric matrix behaves like a "positive number" (e.g. optimization, covariance matrices).

12. Singular Value Decomposition (SVD)

A = UΣVT  (any m × n matrix)
  • Columns of U = eigenvectors of AAT; columns of V = eigenvectors of ATA; both share the same nonzero eigenvalues.
  • Singular values σi = √λi, placed in descending order on the diagonal of Σ.
  • Shortcut: find the eigen-pairs of the smaller of AAT / ATA first, then get the other side via vi = ATui / σi (or ui = Avi / σi).
  • If A is symmetric positive definite, SVD collapses to diagonalization: A = QΛQT.
  • Use when: factorizing any matrix (square or rectangular) into orthogonal × diagonal × orthogonal pieces.

13. PCA via SVD

X̃ = X - mean(X)    X̃ = UΣVT    Z = UTX̃
  • Center the data first (subtract each feature's row-mean), then take the SVD of the centered matrix.
  • Columns of U = principal components (directions of maximum spread); σi2 = variance captured by each component.
  • PC1 is the direction of highest variance; PC2 is the next-highest direction, forced orthogonal (uncorrelated) to PC1.
  • Use when: reducing high-dimensional, correlated data down to a few informative uncorrelated features.
